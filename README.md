# 📈 Stock Price Numerical Analyzer (NumPy)

This project analyzes stock price data using NumPy and Matplotlib.

## 🔍 Features
- Load stock data using NumPy
- Calculate daily returns
- Measure average return and volatility
- Identify best and worst trading days
- Moving average analysis (5-day & 20-day)
- Detect high-risk trading days
- Cumulative return visualization

## 🛠 Technologies Used
- Python
- NumPy
- Matplotlib
